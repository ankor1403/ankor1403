# 🗺️ КАРТА СЕРВЕРА - ВСЕ ДИРЕКТОРИИ И КОМАНДЫ

## 📁 СТРУКТУРА ДИРЕКТОРИЙ

Ваш сервер имеет такую структуру:

```
/opt/
├── telegram_multi_service/   ← Новый мультипрофильный Telegram сервис (порт 8200)
├── messengers/                ← Старый Telegram сервис (порт 8100)
└── wappi/                     ← Caddy прокси-сервер (порты 80, 443)
```

---

## 🎯 1. TELEGRAM MULTI-SERVICE (Главный сервис)

### Перейти в директорию:
```bash
cd /opt/telegram_multi_service
```

### Посмотреть файлы:
```bash
ls -la
```

### Посмотреть docker-compose.yml:
```bash
cat docker-compose.yml
```

### Посмотреть .env файл (переменные окружения):
```bash
cat .env
```

### Создать/отредактировать .env:
```bash
nano .env
# Или если nano не установлен:
vi .env
```

Должно содержать:
```
TELEGRAM_API_ID=28561380
TELEGRAM_API_HASH=c07bd084d44bb8f3d377aa6e1ea859ff
DATABASE_PATH=/app/data/multi.db
SECRET_KEY=ваш_секретный_ключ
```

### Команды управления:

#### Запустить сервис:
```bash
cd /opt/telegram_multi_service
docker-compose up -d
```

#### Остановить сервис:
```bash
cd /opt/telegram_multi_service
docker-compose down
```

#### Перезапустить сервис:
```bash
cd /opt/telegram_multi_service
docker-compose restart
```

#### Пересобрать и запустить (после изменения кода):
```bash
cd /opt/telegram_multi_service
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

#### Посмотреть логи:
```bash
cd /opt/telegram_multi_service
docker-compose logs -f
# Или только telegram-multi-service:
docker logs -f telegram-multi-service
```

#### Посмотреть последние 50 строк логов:
```bash
docker logs --tail=50 telegram-multi-service
```

#### Зайти внутрь контейнера:
```bash
docker exec -it telegram-multi-service bash
# Или если bash нет:
docker exec -it telegram-multi-service sh
```

#### Установить зависимости в контейнере:
```bash
docker exec telegram-multi-service pip install qrcode[pil]
docker exec telegram-multi-service pip install --upgrade telethon
```

#### Проверить статус:
```bash
cd /opt/telegram_multi_service
docker-compose ps
```

## 🌐 3. CADDY ПРОКСИ (NGINX альтернатива)

### Перейти в директорию:
```bash
cd /opt/wappi
```

### Посмотреть файлы:
```bash
ls -la
```

### Посмотреть Caddyfile (конфигурация прокси):
```bash
docker exec wappi-caddy cat /etc/caddy/Caddyfile
```

### Редактировать Caddyfile:
```bash
# Скопировать из контейнера:
docker cp wappi-caddy:/etc/caddy/Caddyfile ./Caddyfile

# Отредактировать:
nano Caddyfile

# Скопировать обратно:
docker cp ./Caddyfile wappi-caddy:/etc/caddy/Caddyfile

# Перезагрузить конфигурацию:
docker exec wappi-caddy caddy reload --config /etc/caddy/Caddyfile
```

### Команды управления:

#### Перезапустить Caddy:
```bash
cd /opt/wappi
docker-compose restart caddy
```

#### Перезагрузить конфигурацию (без перезапуска):
```bash
docker exec wappi-caddy caddy reload --config /etc/caddy/Caddyfile
```

#### Проверить конфигурацию:
```bash
docker exec wappi-caddy caddy validate --config /etc/caddy/Caddyfile
```

#### Логи Caddy:
```bash
docker logs -f wappi-caddy
```

#### Логи из файла:
```bash
docker exec wappi-caddy tail -f /var/log/caddy/access.log
```


## 📊 6. БАЗА ДАННЫХ

### SQLite база Multi-Service:

Находится внутри Docker volume, доступ через контейнер:

```bash
# Проверить существование:
docker exec telegram-multi-service ls -lh /app/data/

# Запросы к БД:
docker exec telegram-multi-service python3 -c "
import sqlite3
conn = sqlite3.connect('/app/data/multi.db')
cur = conn.cursor()

# Посмотреть всех пользователей:
cur.execute('SELECT * FROM users')
for row in cur.fetchall():
    print(row)

# Посмотреть все профили:
cur.execute('SELECT * FROM profiles')
for row in cur.fetchall():
    print(row)

conn.close()
"
```

### Создать бэкап базы:
```bash
# Копировать из контейнера:
docker cp telegram-multi-service:/app/data/multi.db ~/multi.db.backup.$(date +%Y%m%d_%H%M%S)

# Проверить:
ls -lh ~/multi.db.backup.*
```

### Восстановить базу из бэкапа:
```bash
# Остановить сервис:
cd /opt/telegram_multi_service && docker-compose down

# Скопировать бэкап обратно:
docker cp ~/multi.db.backup.YYYYMMDD_HHMMSS telegram-multi-service:/app/data/multi.db

# Запустить сервис:
cd /opt/telegram_multi_service && docker-compose up -d
```

## 🚀 8. ПОЛНОЕ РАЗВЕРТЫВАНИЕ С НУЛЯ

Если нужно развернуть всё заново:

### Шаг 1: Остановить всё
```bash
cd /opt/telegram_multi_service && docker-compose down
cd /opt/messengers && docker-compose down
cd /opt/wappi && docker-compose down
```

### Шаг 2: Очистить (опционально, ОСТОРОЖНО!)
```bash
# Удалить volumes (УДАЛИТ ВСЕ ДАННЫЕ!)
docker volume prune
```

### Шаг 3: Проверить конфигурации
```bash
# Multi-Service:
cd /opt/telegram_multi_service
cat docker-compose.yml
cat .env

# Messengers:
cd /opt/messengers
cat docker-compose.yml

# Wappi:
cd /opt/wappi
cat docker-compose.yml
```

### Шаг 4: Пересобрать образы
```bash
cd /opt/telegram_multi_service && docker-compose build --no-cache
cd /opt/messengers && docker-compose build --no-cache
cd /opt/wappi && docker-compose build --no-cache
```

### Шаг 5: Запустить по порядку
```bash
# 1. Сначала основные сервисы:
cd /opt/messengers && docker-compose up -d
cd /opt/telegram_multi_service && docker-compose up -d

# 2. Подождать 10 секунд:
sleep 10

# 3. Потом прокси:
cd /opt/wappi && docker-compose up -d
```

### Шаг 6: Проверить
```bash
docker ps
curl -I https://telegram.afonin-lisa.ru/
```

## 🆘 10. УСТРАНЕНИЕ ПРОБЛЕМ

### Если сервис не запускается:
```bash
# 1. Посмотреть логи:
docker logs --tail=100 telegram-multi-service

# 2. Проверить порты:
netstat -tlnp | grep 8200

# 3. Проверить конфигурацию:
cd /opt/telegram_multi_service
cat docker-compose.yml
cat .env

# 4. Пересоздать контейнер:
docker-compose down
docker-compose up -d
```

### Если домен не работает:
```bash
# 1. Проверить Caddy:
docker logs --tail=50 wappi-caddy

# 2. Проверить конфигурацию:
docker exec wappi-caddy cat /etc/caddy/Caddyfile

# 3. Перезагрузить Caddy:
docker exec wappi-caddy caddy reload --config /etc/caddy/Caddyfile

# 4. Проверить DNS:
nslookup telegram.afonin-lisa.ru
```

### Если база данных сломалась:
```bash
# 1. Проверить существование:
docker exec telegram-multi-service ls -lh /app/data/

# 2. Попробовать открыть:
docker exec telegram-multi-service python3 -c "
import sqlite3
try:
    conn = sqlite3.connect('/app/data/multi.db')
    print('БД OK')
    conn.close()
except Exception as e:
    print(f'БД ОШИБКА: {e}')
"

# 3. Если нужно - пересоздать:
cd /opt/telegram_multi_service
docker-compose down
docker volume rm telegram_multi_service_data
docker-compose up -d
```
