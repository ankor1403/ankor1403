🔧 УСТРАНЕНИЕ ПРОБЛЕМ:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Проблема: "docker: permission denied"
Решение:
  usermod -aG docker $USER
  exit
  # Зайти заново

Проблема: "порт уже занят"
Решение:
  # Посмотреть что занимает порт:
  netstat -tlnp | grep :80
  # Остановить конфликтующий сервис:
  docker stop ИМЯ_КОНТЕЙНЕРА

Проблема: Контейнеры не запускаются
Решение:
  cd ~/lisa
  docker-compose logs
  docker-compose down
  docker-compose up -d

Проблема: Нет доступа к веб-интерфейсу
Решение:
  # Открыть порты в firewall:
  ufw allow 80/tcp
  ufw allow 443/tcp
  ufw allow 8001/tcp
  ufw allow 8005/tcp
